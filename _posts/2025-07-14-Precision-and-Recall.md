## 생성 모델의 평가 지표: 정밀도(Precision)와 재현율(Recall)

### 1. FID의 한계
![](/assets/images/2025-07-14/FID_bad2.png)
* **FID**는 생성된 이미지의 품질과 다양성을 한 번에 평가하는 지표로, 품질(Fidelity)과 다양성(Diversity)을 개별적으로 평가하기 어렵습니다.
* 예를 들어, 두 생성 모델의 FID 점수가 비슷하더라도, 하나는 품질에 집중했을 수도 있고, 다른 하나는 다양성에 집중했을 수도 있습니다.

### 2. 판별 모델에서의 정밀도와 재현율 개념
![](/assets/images/2025-07-14/classification_pr.png)
* **정밀도(Precision)**: 모델이 양성으로 예측한 결과 중 실제로 양성인 비율.

$$
Precision = \frac{TP}{TP+FP}
$$

* **재현율(Recall)**: 실제 양성인 데이터 중 모델이 양성으로 맞게 예측한 비율.

$$
Recall = \frac{TP}{TP+FN}
$$

### 3. 생성 모델에서의 정밀도와 재현율 개념
![](/assets/images/2025-07-14/precision.png)
* **생성 모델의 정밀도(Precision)**:
  * 생성된 데이터 중 실제 데이터 분포와 매우 가까운 데이터의 비율을 측정합니다.
  * 정밀도가 높으면 품질이 높다고 판단할 수 있습니다.

![](/assets/images/2025-07-14/recall.png)
* **생성 모델의 재현율(Recall)**:

  * 실제 데이터 중 생성된 데이터 분포와 매우 가까운 데이터의 비율을 측정합니다.
  * 재현율이 높으면 다양성이 뛰어나다고 판단할 수 있습니다.

### 4. 개선된 정밀도와 재현율 계산 방법

* **근방(Close to)** 정의:
![](/assets/images/2025-07-14/close_to.png)
  * k-NN (k-Nearest Neighbors) 방식을 활용해 특정 반경 내에 존재하는 데이터를 "근방에 속한 데이터"로 정의합니다.

* **개선된 정밀도 계산 방법**:
![](/assets/images/2025-07-14/improved_precision.png)
  * 생성된 데이터 중 실제 데이터 분포 내에 존재하는 비율을 계산.
  * 생성된 데이터 기준으로 실제 데이터에 속하는 정도 평가.

* **개선된 재현율 계산 방법**:
![](/assets/images/2025-07-14/improved_recall.png)
  * 실제 데이터 중 생성된 데이터 분포 내에 존재하는 비율을 계산.
  * 실제 데이터를 얼마나 잘 커버했는지 평가.

### 5. 한계점

* 이상치(Outlier)에 민감하며, 소수의 데이터가 이동해도 점수가 크게 변할 수 있습니다.
![](/assets/images/2025-07-14/improved_bad1.png)
![](/assets/images/2025-07-14/improved_bad2.png)
* 실제 데이터와 생성된 데이터가 동일한 분포를 가지더라도 샘플링 방식에 따라 평가 점수가 낮게 나올 수 있습니다.
![](/assets/images/2025-07-14/improved_bad3.png)
* 계산할 때 마다 생성된 데이터를 매번 확인해야 해서 계산량이 많습니다.
* 훈련 과정에서 특정 클래스를 학습하지 않아도 민감하지 않게 반응할 수 있습니다.
* 매개변수(k, 실제 데이터 크기, 생성 데이터 크기 등)에 민감하여 불안정할 수 있습니다.

### 6. 한계점 개선 방법: Density와 Coverage
![](/assets/images/2025-07-14/improved_alleviate.png)
* **Density**: 데이터를 단순 반경이 아닌 가중합집합으로 계산하여 이상치에 덜 민감하도록 개선.
* **Coverage**: 생성 데이터마다 매번 계산하지 않고, 실제 데이터 집합에 미리 계산하여 안정성을 확보하고 계산량을 줄임.

### 7. 요약 및 활용

* 정밀도와 재현율은 각각 품질과 다양성을 개별적으로 평가할 수 있는 지표입니다.
* 품질과 다양성은 트레이드오프 관계에 있어, 상황에 따라 적절히 지표를 선택하여 평가해야 합니다.
