# IS & FID
> 서론 : 정답이 있는 분류 문제는 평가가 쉽지만, 생성 모델은 결과 평가를 위한 별도의 기준이 필요합니다. \
> IS와 FID는 이를 위한 대표적인 지표입니다.


## 1. 생성 모델을 평가할 때 중요한 두 가지

![](/assets/images/2025-07-14/Fidelity-and-Diversity.png)

| 평가 항목               | 의미                        |
| ------------------- | ------------------------- |
| **품질 (Fidelity)**   | 이미지가 얼마나 **선명하고 현실적**인지   |
| **다양성 (Diversity)** | 여러 유형의 이미지를 **골고루** 생성했는지 |

> 문제: 픽셀 비교로는 품질만 보고, **진짜 '다양한 분포'를 학습했는지 알기 어렵다.** \
> 해결: **사전 학습된 분류기**의 '특징 벡터'를 이용해 평가한다.

---

## 2. Inception Score (IS)

### 핵심 개념

* **Inception V3 모델**을 이용해 생성 이미지의 **분류 확신도**를 평가함
* **높을수록** 좋은 성능 (좋은 품질 + 높은 다양성)

### 평가 원리

#### ① 품질 판단
![](/assets/images/2025-07-14/Sharpness.png)
* 예리한 이미지일수록 **한 클래스로 확실하게 분류됨**
  → 분류 확률이 특정 클래스에 몰림 → **낮은 엔트로피**
  → 모델이 확실한 이미지를 만들었다는 뜻

#### ② 다양성 판단
![](/assets/images/2025-07-14/Diversity.png)
* 다양한 이미지를 생성했다면, 여러 클래스가 고르게 나옴 → **높은 마지널 엔트로피**
  → 즉, 생성 이미지가 한쪽으로 치우치지 않음

### 단점

* **ImageNet 기반이므로 얼굴 등 다른 분야에 부적합**
![](/assets/images/2025-07-14/IS_bad1.png)
* **같은 고품질 이미지를 반복 생성**해도 높은 점수 (Mode Collapse 감지 불가)
![](/assets/images/2025-07-14/IS_bad2.png)
* **노이즈 이미지도 속일 수 있음**
![](/assets/images/2025-07-14/IS_bad3.png)

## 3. Fréchet Inception Distance (FID)

### 핵심 개념
![](/assets/images/2025-07-14/FID1.png)
* IS의 한계를 보완하기 위해 등장
* \*\*"실제 이미지와 생성 이미지의 분포 차이"\*\*를 수치화
* **낮을수록** 좋은 모델 (실제 데이터 분포와 가까움)

### 계산 원리

1. Inception 모델로 이미지의 **특징 벡터** 추출
2. 실제 이미지와 생성 이미지 각각의 **평균(μ)**, **공분산(Σ)** 계산
3. 이 두 분포 사이의 **거리(FID score)** 계산

### 장점

* **품질+다양성 통합 평가**
* **데이터셋 제한 없음 (얼굴, 그림 등 OK)**
* IS보다 **조작에 강함**
* **사람의 인식 결과와 더 유사함**

### 단점
![](/assets/images/2025-07-14/FID_bad1.png)
* **품질과 다양성을 따로 구분해서 평가 불가**
* 무조건 숫자만 낮다고 해서 "품질이 좋다" 혹은 "다양하다"라고 단정하기 어려움

---

## 4. 요약 비교

| 항목        | Inception Score (IS)       | Fréchet Inception Distance (FID) |
| --------- | -------------------------- | -------------------------------- |
| 의미        | 예리함 + 다양성 판단               | 생성 이미지가 실제 이미지 분포와 얼마나 비슷한지      |
| 높을수록/낮을수록 | 높을수록 좋음                    | 낮을수록 좋음                          |
| 사용 모델     | Inception V3               | Inception V3                     |
| 장점        | 직관적, 품질+다양성 함께 평가          | 데이터셋 제약 없음, 더 안정적                |
| 단점        | 조작 가능, Mode Collapse 탐지 불가 | 품질·다양성 따로 평가 불가                  |

---

## 📌 요점

* **IS**는 "얼마나 잘 만들어졌고, 다양하게 만들었나?"
* **FID**는 "실제 데이터처럼 만들었나?"
* FID는 조작에 강하고 더 현실적인 평가 가능
* IS는 빠르게 결과 볼 때 유용하지만 조심해서 해석해야 함
